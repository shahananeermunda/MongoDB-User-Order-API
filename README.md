# User & Order Management API

A RESTful API built using **Node.js, Express.js, MongoDB, and Mongoose** to manage users and orders.

## Technologies Used
- Node.js
- Express.js
- MongoDB
- Mongoose
- JavaScript
- dotenv

## Features
- User CRUD operations
- Order CRUD operations
- MongoDB integration using Mongoose
- Schema validation
- Async/await database operations
- Centralized error handling
- Proper HTTP status codes

## Installation

**1. Clone the repository**
```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

**2. Install dependencies**
```bash
npm install
```

**3. Start the server**
```bash
node server.js
```

Server URL: `http://localhost:3000`

## API Testing

Test all endpoints using Postman with GET, POST, PUT, PATCH, and DELETE methods.
